# Migrations

Alembic reads the database URL from `app.core.config.settings`, so the same
environment variables drive the API and the migrations.

```bash
alembic upgrade head                      # apply
alembic downgrade -1                      # roll back one revision
alembic revision --autogenerate -m "msg"  # create a revision from model changes
alembic current                           # show applied revision
```

Always review autogenerated revisions before committing them.
